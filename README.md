# C Programming Practice

A collection of C programs created to practice programming fundamentals, improve problem-solving skills, and build a strong foundation in C.

## 📚 Topics Covered

* Basic Input and Output
* Variables and Data Types
* Operators
* Conditional Statements (`if-else`, `switch`)
* Loops (`for`, `while`, `do-while`)
* Patterns
* Functions
* Arrays
* Strings
* Pointers
* Structures
* Recursion
* File Handling

## 🛠️ Language & Tools

* **Language:** C
* **Compiler:** GCC
* **IDE:** Visual Studio Code


## 🎯 Purpose

* Practice C programming concepts.
* Improve logical thinking and problem-solving skills.
* Strengthen programming fundamentals.
* Maintain a record of my coding practice.

## 🚀 How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Compile a C program using GCC.
